## 1. The game in one paragraph

You pilot a fictional rover, *Voyage*, from launch to Mars. There you find the three rovers NASA left behind, in order: **Sojourner → Spirit → Opportunity**. At each one you learn its real story through a timeline, real NASA photos and a chat with the rover. You also survive the hazard that ended its mission: power in the dust for Sojourner, soft soil for Spirit, a planet-wide dust storm for Opportunity. A quiet ending follows, where your own rover looks back at Earth, and then a "Data Beamed Home" debrief. A full run takes about 10 minutes.

## 4. Key decisions (and why)

| Decision | Why |
|---|---|
| Phaser 3.90.0 pinned, mounted client-only (`ssr:false`), one game per run | The spec locks Phaser 3, and Phaser can't run on the server. |
| React overlay for all UI, scaled with CSS `zoom` over a 1280×720 canvas | Crisp text and easy forms. `transform` broke focus and scrolling. |
| One in-memory run store shared by Phaser and React; no saving | A 10-minute run with nothing to persist. |
| Gemini `gemini-3.5-flash-lite`, key server-side only, facts-only prompt, offline fallback, 12 questions/min per IP | Cheap and fast. Answers stay accurate, and the demo works even without Wi-Fi. |
| Sojourner = teaching leg; Spirit = stuck in soft soil → traction mode; Opportunity = storm → power preservation | Each leg teaches one mechanic, tied to how that rover's mission actually went. |
| Weather by leg: clear → dusty → dust storm | Shows all three solar-charging conditions. |
| Our lander uses a sky crane, never airbags or petals | So it's never mistaken for Pathfinder. The 1997 flashback is sepia, clearly labelled, and ends on a real NASA photo (PIA00611). |
| Landing order follows the narration (Nov 15, Phase F) | Approach → 1997 flashback (lines 2–3) → present-day entry, sky crane, touchdown (lines 4–6). Replaces appflow §2.5's "our touchdown, then flashback" order so every line plays over its own pictures. |
| Discovery no longer auto-jumps (Nov 15, Phase H) | After a leg is complete the closing dialogue just closes. A "jump point" beacon lights up a short drive away, the guidance arrow points to it, and inside its ring the player chooses when to jump (E or the JUMP button) — or keeps exploring. The jump screen is an animated schematic map with both real rover sites and the great-circle distance (≈9,000 km Ares Vallis→Gusev, ≈9,700 km Gusev→Endeavour). Supersedes appflow §2.6–2.9 and prd §4.3 (auto jump-cut); those docs still need the same update. |
| Narration: ElevenLabs voices "Martin" (Mission Control) and "Mina" (our rover) | Free plan, so it's non-commercial and must credit **elevenlabs.io** (done on the title and end screens). |
| Music and SFX synthesized with the Web Audio API | Original, no licensing, tiny download. |
| Subtitles always on; each line waits for its voice clip | The story still works with the sound off or if audio fails. |
| No NASA logos in generated art; AI art watermarked "PIXEL ART: AI-GENERATED" | Space Apps 2026 AI rules. |
| Wheel spin pre-rendered by a script (`npm run wheel-spin`) | Small files (~170 KB). Struts and wheel outlines never smear. |

## 5. How the game is built

```
voyage/src/
  app/              Next.js pages + /api/chat route
  game/
    scenes/         Boot (loader + stage director), Opening, Rocket, Landing, Surface, Ending
    state/          runStore: the single run state + all mission actions
    audio/          engine (Web Audio), director (state → music/SFX), voiceClips registry
    art.ts          procedural cinematic art, ground tile, wheel-spin spritesheets
    legs.ts         the three legs: world size, spawn, target, weather, hazards
    tuning.ts       every balance number in one place
    cinematic.ts    subtitle + voice timing
  chat/             askRover (live → fallback), fallback answers
  server/           Gemini client, facts-only prompt, rate limiter
  content/          verbatim scripts + rover fact sheets
  ui/               HUD, Rover Hub, dialogue, pause, title/destination/debrief screens
scripts/            tag-voice.mjs (AI note in MP3 metadata), make-wheel-spin.mjs
public/assets/      rover sprites (+ spin overlays), terrain, props, NASA photos, voice MP3s
```

**Controls:** WASD / arrow keys drive · E scan / use tool · T Rover Hub · C quick charge (2 coins → +50% battery) · Esc or P pause · M mute.

**Main tuning values** (`src/game/tuning.ts`):
- Drive speed 170 and drain 4%/s. In the storm, driving drains 1.25× as fast.
- Solar charge per second: clear 6%, dusty 3.5%, dust storm 2.2%.
- Low-battery warning at 25%.
- Storm survival: hold still for 8 s.
- Coins: start with 3, +5 per discovery.

Measured leg times: Sojourner ~12 s, Spirit ~39 s, Opportunity ~32 s, rocket ~27 s.

## 6. Problems hit and fixed

| Problem | Fix |
|---|---|
| Server crash "window is not defined" | Moved the shared constants into a Phaser-free `constants.ts`. |
| UI scrolled or jumped when focusing buttons | Switched the overlay scaling to CSS `zoom` and used `preventScroll`. |
| Soft soil looked like mud | Paler, sandy palette (the rules say "not mud"). |
| Chat added suggestions to every answer and said "in UTC time" | Tightened the prompt rules and cleaned the fact sheet. |
| Cinematic lines skipped while a scene was starting | Better "scene gone" check (`isGone`). |
| Rocket mini-game far too long (~90 s) | Retuned to ~27 s. |
| Opportunity leg too punishing (90 s+) | Gentler storm drain and charge, shorter leg. |
| "Constant buzzing" sound | Charging tone → one-off chime, drive hum → soft rumble, softer music waves, quieter thrust. |
| Live chat said "Gemini unreachable" | Hidden `\r` in the Vercel env var; the key is now trimmed. |
| Canvas didn't refit after a window resize | A ResizeObserver refreshes the Phaser scale. |
| ElevenLabs free tier kept refusing requests | The team generated the remaining clips by hand from `ELEVENLABS_PROMPT.md`. |

## 7. Deploying

- Vercel project `arifhaxns-projects/voyage`. `GEMINI_API_KEY` is set for **production only** and is never committed (`.env.local`, `.vercelignore`).

  ```bash
  vercel deploy --prod --yes
  ```
